Да, принимаю ваши уточнения. Тогда фиксируем стандарт так, чтобы шаблон можно было отдать специалистам и он не превращался в «свободное творчество».

Главный принцип:

> **Верхнеуровневые блоки из реальных ИВ-заключений не пропускаем.  
> Пропускать можно только конкретные формулировки внутри блока, если вместо них ставится служебная отметка: «не наблюдалось», «не проверялось», «не релевантно», «значимых изменений не зафиксировано».**

# 1. Минимальный обязательный набор блоков

Если мы берём за эталон ваши реальные заключения по направлению ИВ — например, Марченко и Пюрвяева, — то минимальный набор такой:

| № | Блок | Обязателен? | Что минимум должен содержать |
|---|---|---:|---|
| 0 | Идентификация документа | Да | ФИО, дата рождения, период реабилитации, специалист, количество занятий |
| 1 | Актуальное состояние | Да | Интерес к миру, эмоциональный фон/саморегуляция, сенсорный профиль, контакт/коммуникация, игра, речь/невербалика |
| 2 | Цели на период реабилитации | Да | Хотя бы одна цель по выявленной зоне роста; если целей нет — «цели предыдущего периода сохраняются» |
| 3 | Приёмы работы | Да | Приёмы, соответствующие целям; обязательно с примерами с занятий |
| 4 | Результаты | Да | Либо стабильные изменения, либо «значимых изменений не зафиксировано» |
| 5 | Цели на следующий период | Да | Либо продолжение прежних целей, либо новые цели, выведенные из результатов |
| 6 | Рекомендации | Да | Домашний перенос приёмов работы; понятный язык; минимум несколько обязательных смысловых тем |
| 7 | Рекомендуемая литература | Да | Утверждённый список центра, без сокращения под конкретного ребёнка |

То есть **минимальный набор — 8 блоков**, если считать идентификацию, или **7 смысловых блоков**, если считать только содержание заключения.

# 2. Какие блоки можно пропускать, если они нерелевантны?

## Короткий ответ

**Ни один из верхнеуровневых блоков пропускать нельзя.**

Если вы сказали: «все блоки из реальных заключений должны оставаться обязательно», значит стандарт такой:

- нельзя удалить блок «Актуальное состояние»;
- нельзя удалить блок «Цели»;
- нельзя удалить блок «Приёмы работы»;
- нельзя удалить блок «Результаты»;
- нельзя удалить блок «Цели на следующий период»;
- нельзя удалить блок «Рекомендации»;
- нельзя удалить блок «Рекомендуемая литература».

Но внутри блоков можно не использовать все возможные фразы.

---

## Что можно пропускать внутри блоков

Можно пропускать:

1. Конкретные формулировки из банка фраз.
2. Детализацию по способностям, которые не проверялись или не релевантны.
3. Длинные перечисления, если они не нужны.
4. Повторы одних и тех же мыслей разными словами.

Нельзя пропускать:

1. Сам блок.
2. Обязательные микротемы внутри блока.
3. Связь «наблюдение → статус → цель → приём → рекомендация».
4. Примеры с занятий там, где они обязательны.

# 3. Обязательные микротемы внутри блока «Актуальное состояние»

В ваших реальных ИВ-заключениях актуальное состояние почти всегда включает несколько обязательных тем. Чтобы специалисты не начинали писать «с чего попало», я бы зафиксировал внутри блока 1 шесть обязательных микроблоков.

| Микроблок | Обязателен? | Что пишем |
|---|---:|---|
| 1.1 Интерес к миру, игрушкам, людям, играм | Да | Проявляет / избирательно / снижен / только в знакомой деятельности |
| 1.2 Эмоциональный фон, саморегуляция, фрустрация | Да | Спокойный / тревожный / лабильный / регулируется / не справляется / уходит из контакта |
| 1.3 Сенсорная переработка информации | Да | Повышенная / сниженная / смешанная чувствительность, сенсорный поиск, избегание, аутостимуляции |
| 1.4 Контакт, совместное внимание, инициатива, цепочки общения | Да | Замечает / отвечает / не инициирует / инициирует / цепочки 1–2 шага / несколько шагов |
| 1.5 Игра: уровень, предпочтения, сюжет, правила | Да | Сенсомоторная / функциональная / символическая / сюжетная / сюжетно-ролевая / с правилами |
| 1.6 Коммуникация, речь, понимание, невербальные средства | Да | Жест / взгляд / вокализации / слова / фразы / понимает инструкции / не использует речь |

Если по какой-то микротеме нет данных, специалист не удаляет её, а пишет служебную фразу.

Примеры служебных фраз:

> По данной способности наблюдение не проводилось из-за высокой тревожности ребёнка в начале занятия.

> Взаимодействие со сверстниками в данный период не организовывалось.

> Речевые средства коммуникации не используются; преимущественно невербальное общение.

> Выраженных особенностей сенсорной переработки, требующих отдельного описания, не наблюдалось.

> Способность не проверялась из-за отказа ребёнка от контакта в предложенной деятельности.

Так блок остаётся обязательным, но не наполняется выдумками.

# 4. Ваши правила статусов: переводим в рабочий код

Вы дали очень важные операциональные правила. Теперь их нужно зафиксировать как коды, чтобы специалист мог заполнять шаблон без нейросети.

## Статусы

| Код | Название | Когда ставим | Куда попадает |
|---|---|---|---|
| **S3** | Стабильно | Ребёнок проявляет способность сам, без помощи взрослого, при невключённом наблюдении специалиста. По вашему правилу: даже если видели один раз, но проявление яркое и самостоятельное — можно считать стабильным | Актуальное состояние; при наличии динамики — Результаты |
| **S2** | Иногда | Ребёнок проявляет способность по собственной инициативе, но нестабильно, фрагментарно, не во всех ситуациях, либо проявление есть, но специалист не может считать его устойчивым ресурсом | Актуальное состояние сQualifier «иногда / избирательно»; Цели на период |
| **S1** | С поддержкой | Способность проявляется только после того, как специалист использовал слово, действие, аффект или создал подходящие условия | Актуальное состояние с указанием поддержки; Цели; Приёмы |
| **S0** | Не проявляется | При достаточном количестве возможностей способность не наблюдалась | Цели на более базовом уровне |
| **SN** | Не проверялось / стресс | Ребёнок был перегружен, болен, в новой среде, отказывался от контакта, способность нельзя оценить корректно | Служебная отметка; приоритет — саморегуляция и стадия 1 |

---

## Как отличить S3 от S2 и S1

### S3 — стабильно

Ставим, если:

- ребёнок сделал сам;
- взрослый не подсказывал;
- взрослый не начинал действие;
- взрослый не давал игрушку как триггер;
- взрослый не использовал specjalną интонацию, чтобы «вытащить» реакцию;
- наблюдение было невключённым: специалист просто присутствовал и фиксировал.

Пример:

> Ребёнок самостоятельно подошёл к песочнице, начал играть с песком, посмотрел на педагога, улыбнулся и продолжил игру без подсказок.

Это может быть S3, если проявление явное и самостоятельное.

В документе:

> Проявляет интерес к сенсорной деятельности с песком. Самостоятельно вовлекается в игру, поддерживает эмоциональный контакт без прямой поддержки взрослого.

---

### S2 — иногда

Ставим, если:

- ребёнок проявляет способность сам, но не постоянно;
- есть «островки» способности;
- в одной ситуации проявляет, в другой нет;
- проявление зависит от настроения, усталости, знакомства со средой;
- специалист видит инициативу, но не может назвать это устойчивым ресурсом.

Пример:

> В знакомой игре ребёнок самостоятельно инициирует контакт взглядом, но в новой деятельности инициатива не проявляется.

В документе:

> Инициатива контакта проявляется избирательно: в знакомой сенсорной игре ребёнок может самостоятельно привлечь внимание взрослого взглядом, однако в новых ситуациях инициатива не устойчива.

Цель:

> Развивать устойчивость самостоятельной инициативы в контакте за счёт переноса успеха из знакомой игры в более широкие игровые ситуации.

---

### S1 — с поддержкой

Ставим, если ребёнок проявил способность только после того, как специалист:

- сказал слово;
- задал вопрос;
- назвал действие;
- показал игрушку;
- начал сюжет;
- дал предмет в руку;
- использовал интонацию;
- применил мимику;
- создал эмоциональный аффект;
- организовал подходящее условие.

Ваш пример:

> Ребёнок молчал, но когда ему показали знакомую сюжетную игрушку, начал рассказывать сюжет и разыгрывать его.

Это **не S3**. Это **S1**.

Потому что условие создал взрослый.

В документе:

> Сюжетная игра проявляется при создании поддерживающих условий: при предъявлении знакомой сюжетной игрушки ребёнок начинает проговаривать и разыгрывать сюжет. Самостоятельно сюжетную инициативу не проявляет.

Цель:

> Развивать самостоятельную инициативу в сюжетной игре за счёт постепенного уменьшения внешней поддержки.

Приём:

> Сначала включать знакомую сюжетную игрушку как опору, затем после первого действия делать паузу и ожидать самостоятельного продолжения ребёнка. При необходимости усиливать ожидание мимикой и интонацией, но не подсказывать сюжет целиком.

Пример с занятия:

> На занятии педагог показал знакомую игрушку-поварёшку. Ребёнок начал кормить куклу. После этого педагог замолчал и выжидательно посмотрел на ребёнка. Через несколько секунд ребёнок самостоятельно добавил действие: «ещё», продолжив сюжет.

# 5. Что считать «поддержкой взрослого»

Чтобы специалисты не спорили, нужно зафиксировать простой список.

Поддержка — это любое из:

| Тип поддержки | Примеры |
|---|---|
| Слово | Инструкция, вопрос, название действия, подсказка, «давай покормим», «что дальше?» |
| Действие | Показать игрушку, начать действие, дать предмет, физически направить, начать сюжет |
| Аффект | Явная мимика, интонация, эмоциональное заражение, юмор, удивление, пауза с ожиданием |
| Условие | Знакомая игрушка, сенсорная коробка, сниженный шум, визуальная опора, привычный ритуал, предварительный показ |

Если без этого ребёнок способность не проявил — это **S1**, а не S3.

# 6. Как это вшить в шаблон

В шаблоне для каждой ключевой способности нужно сделать не просто фразу, а строку с кодом статуса и примером.

## Рабочая структура строки

```text
[Сфера]
[Статус: S3 / S2 / S1 / S0 / SN]
[Формулировка для документа]
[Пример с занятия]
[Цель, если статус S2/S1/S0/SN]
[Приём, если есть цель]
[Рекомендация семье]
```

Но в итоговом документе специалист видит более простую форму.

`[Например: ребёнок использовал слово «ещё», чтобы продолжить качание, но не использовал речь для обращения за помощью.]`

---

## 2. Цели на период реабилитации

> Цели ставятся из статусов S2, S1, S0 и SN.  
> Если способность стабильна S3, цель не ставится как «сформировать», но может ставиться как «расширить» или «перенести в новые ситуации».

Формат:

```text
Цель 1. [Формулировка цели]
Основание: [статус, например S1]
Что развиваем: [способность]
```

Примеры:

- Развивать самостоятельную инициативу в контактном взаимодействии.
- Увеличивать количество коммуникативных циклов без прямой поддержки взрослого.
- Переводить сюжетную игру из состояния «проявляется при предъявлении знакомой игрушки» в состояние самостоятельной игровой инициативы.
- Развивать способность обращаться за помощью в ситуации затруднения.
- Снижать тревожность через предсказуемость и сенсорную регуляцию.
- Расширять репертуар сенсорных и двигательных игр как основы эмоционального контакта.

Если целей нет:

> Цели предыдущего периода сохраняются. Новые цели не вводятся до стабилизации эмоционального контакта и саморегуляции.

---

## 3. Приёмы работы

> Каждый приём должен соответствовать цели.  
> В этом блоке обязательно нужны конкретные примеры с занятий.  
> Общие фразы без примера не считаются заполненным блоком.

Формат:

```text
Приём к цели 1. [Что делает специалист]
Пример с занятия: [короткий факт]
```

Пример:

```text
Приём: создавать мягкие игровые препятствия, требующие участия взрослого, и делать паузы для появления инициативы ребёнка.

Пример с занятия: педагог положил желаемую игрушку в прозрачную коробку, не закрывая её полностью. Ребёнок потянулся, но не смог достать. Педагог выжидательно посмотрел и эмоционально прокомментировал: «Ого, не достаёшь?». Ребёнок посмотрел на педагога, протянул руку и вокалилизировал. Педагог помог открыть коробку после коммуникативного обращения.
```

---

## 4. Результаты

> В результаты помещаем только то, что ребёнок показывает стабильно.  
> По вашему правилу: если способность проявлена самостоятельно, без поддержки, даже за одно наблюдение, её можно фиксировать как стабильное проявление, но желательно помечать, что это однократное яркое наблюдение.  
> Всё, что было «иногда» или «с поддержкой», в результаты не переносим как устойчивое достижение.

Формат:

```text
Было: [что было ранее или чего не было]
Стало: [что стабильно проявляется сейчас]
Доказательство: [пример или тип наблюдения]
```

Пример:

> У педагога и ребёнка установился более устойчивый эмоциональный контакт. Ребёнок стал самостоятельно проявлять радость при встрече и в процессе игры. Зрительный контакт стал более частым. Ребёнок начал использовать отдельные слова для продолжения игры.

Если изменений нет:

> За период реабилитации значимых устойчивых изменений по направлению «Игровое взаимодействие» не зафиксировано. Выявленные трудности сохраняются. Работа продолжается по целям предыдущего периода.

---

## 5. Цели на следующий период

> Формируются из незакрытых целей и новых зон роста.

Примеры:

- Продолжать работу над самостоятельной инициативой в контакте.
- Увеличивать длину коммуникативных цепочек.
- Развивать сюжетную игру без обязательной опоры на знакомую игрушку.
- Поддерживать способность обращаться за помощью.
- Расширять репертуар совместных игр.
- Развивать игры с правилами, если ребёнок готов.

Если новых целей нет:

> Цели предыдущего периода сохраняются. Приоритет — закрепление полученных результатов и перенос навыков в более широкие игровые ситуации.

---

## 6. Рекомендации

> Рекомендации должны быть понятны родителям или законным представителям.  
> Лучше писать по схеме: что делать — как делать — зачем.  
> Термины типа «коммуникативные циклы», «со-регуляция», «праксис» нужно переводить на бытовой язык.

Минимальные обязательные смысловые темы внутри блока «Рекомендации»:

| Тема | Обязательна? | Что пишем |
|---|---:|---|
| Ежедневное общение без требований | Да | 15–20 минут, присоединение к деятельности ребёнка, без требований |
| Следование за интересом и мягкие препятствия | Да | Встраиваться в игру, добавлять новое, создавать ситуации, где ребёнок вынужден обращаться к взрослому |
| Сенсорная среда и регуляция состояния | Да | Свет, звук, темп, количество предметов, движение, перегрузка, переключение |
| Поддержка игры, инициативы и эмоций | Да | Сюжет, символы, двигательные игры, озвучивание чувств, ожидание инициативы |
| Фрустрация, границы, правила | Да | Спокойные границы, помощь в трудной ситуации, обращение за помощью, ожидание, очередь |
| Социальное взаимодействие / сверстники | По релевантности | Если не проверялось — служебная фраза |

Пример служебной фразы:

> Взаимодействие со сверстниками в данный период не организовывалось, поэтому рекомендации по этой сфере будут добавлены при появлении соответствующих наблюдений.

---

## 7. Рекомендуемая литература

> Блок обязателен.  
> Список берётся из утверждённого шаблона центра.  
> Не сокращать и не заменять под конкретного ребёнка, если это не решение руководства.

# 8. Как специалисты должны заполнять шаблон: пайплайн

## Шаг 1. Наблюдение

Специалист фиксирует факт, а не вывод.

Плохо:

> Ребёнок не идёт на контакт.

Хорошо:

> На 2 занятии ребёнок 3 минуты играл с песком самостоятельно. Когда педагог молча сел рядом, ребёнок не отвернулся. Когда педагог взял такую же лопатку, ребёнок посмотрел на него и продолжил копать.

---

## Шаг 2. Кодирование статуса

Специалист отвечает на вопросы:

1. Ребёнок сделал сам?
2. Взрослый подсказывал словом?
3. Взрослый показывал действием?
4. Взрослый использовал эмоцию/интонацию/паузу?
5. Взрослый создал условие: игрушка, среда, ритуал, снижение нагрузки?
6. Наблюдение было невключённым или специалист был включён в игру?
7. Было ли это однократное яркое проявление или повторяющееся?

Далее ставим код:

- сам, без поддержки, ярко — **S3**;
- сам, но нестабильно — **S2**;
- только после слова/действия/аффекта/условия — **S1**;
- не проявил при возможностях — **S0**;
- не проверялось из-за стресса — **SN**.

---

## Шаг 3. Перенос в документ

| Статус | Актуальное состояние | Цели | Приёмы | Результаты |
|---|---|---|---|---|
| S3 | Пишем как ресурс | Можно цель расширения | Приём поддержания и усложнения | Можно в результаты |
| S2 | Пишем с qualifiers «иногда, избирательно» | Цель закрепить | Приём увеличения частоты | Не в результаты, пока не стало S3 |
| S1 | Пишем с указанием поддержки | Цель снять поддержку | Приём постепенного удаления опоры | Не в результаты, пока не стало S2/S3 |
| S0 | Пишем «не наблюдалось» | Цель базового уровня | Приём формирования базы | Не в результаты |
| SN | Пишем «не проверялось» | Приоритет регуляции | Приём стабилизации состояния | Не в результаты |

# 9. Правило примеров с занятий

Вы сказали:

> Нужны примеры из занятий.  
> Нужен запрет на общие фразы без примера.

Значит фиксируем правило:

> Ни одна оценка способности не вносится в документ, если специалист не может привести хотя бы один конкретный пример наблюдения.

Но чтобы документ не стал перегруженным, примеры можно делать короткими.

## Минимальный формат примера

```text
На занятии [номер/дата] в ситуации [условие] ребёнок [действие]. Специалист [без вмешательства / сказал / показал / создал условие]. Ребёнок [последствие].
```

Пример:

> На 3 занятии в ситуации свободной игры с песком ребёнок самостоятельно наполнил формочку, перевернул её и посмотрел на педагога. Педагог не подсказывал. Ребёнок улыбнулся и повторил действие.

Это пример для S3.

Пример для S1:

> На 4 занятии ребёнок не начинал сюжетную игру с куклой. Педагог показал знакомую кухню и начал кормить куклу. Ребёнок подхватил действие и начал кормить вторую куклу.

Это S1, потому что взрослый создал условие и начал сюжет.

# 10. Как не дать шаблону превратиться в копипаст

Нужны три контрольных правила.

## Правило 1. Нет цели без наблюдения

Нельзя написать:

> Развивать сюжетную игру.

Если в актуальном состоянии нет ничего про сюжетную игру.

Правильно:

> Сюжетная игра проявляется при предъявлении знакомой игрушки.  
> Цель: развивать самостоятельную сюжетную инициативу за счёт постепенного удаления опоры.

---

## Правило 2. Нет приёма без цели

Нельзя написать:

> Использовать би-ба-бо.

Если это не связано с целью.

Правильно:

> Цель: увеличивать эмоциональную включённость и количество коммуникативных циклов.  
> Приём: использовать би-ба-бо в коротких ритуалах приветствия и неожиданности, делать паузы после действия игрушки.

---

## Правило 3. Нет рекомендации без домашнего переноса

Нельзя написать специалисту:

> Со-регуляция аффекта.

Для родителей нужно перевести:

> Когда ребёнок расстроился, сначала не объясняйте и не требуйте. Сядьте рядом, говорите тихо, используйте знакомое движение или сенсорную игру, чтобы помочь ему успокоиться. Когда ребёнок перестал напрягаться, можно мягко вернуться к игре.

# 12. Итоговые ответы на ваши два вопроса

## Вопрос 1. Какой минимальный набор блоков обязан быть в каждом документе?

Минимальный обязательный набор:

1. Идентификация: ФИО, дата рождения, период, специалист, количество занятий.
2. Актуальное состояние.
3. Цели на период реабилитации.
4. Приёмы работы.
5. Результаты.
6. Цели на следующий период.
7. Рекомендации.
8. Рекомендуемая литература.

Если считать только смысловые блоки ИВ — это 7 блоков плюс шапка.

---

## Вопрос 2. Какие блоки можно пропускать, если они нерелевантны?

**Верхнеуровневые блоки пропускать нельзя.**

Можно пропускать только внутренние формулировки, если вместо них ставится служебная отметка:

- не наблюдалось;
- не проверялось;
- не релевантно данному периоду;
- значимых изменений не зафиксировано;
- цели предыдущего периода сохраняются.

То есть документ всегда должен содержать все обязательные блоки, но не обязан содержать все возможные фразы внутри них.

# 13. Контрольный чек-лист для специалиста перед выдачей документа

Перед тем как отдать заключение, специалист должен проверить:

1. Все ли обязательные блоки на месте?
2. Есть ли в актуальном состоянии все шесть микротем?
3. Каждая ли ключевая фраза имеет статус S3 / S2 / S1 / S0 / SN?
4. Нет ли слова «стабильно», если ребёнок проявил способность только после подсказки, показа, эмоционального включения или созданного условия?
5. Есть ли пример с занятия для каждого важного вывода?
6. Каждая ли цель вытекает из статуса S2 / S1 / S0 / SN?
7. Есть ли приём на каждую цель?
8. Есть ли хотя бы один конкретный пример в блоке «Приёмы работы»?
9. В результатах написано только стабильное, а не «иногда» и не «с поддержкой»?
10. Рекомендации понятны родителю без терминов?
11. Нет ли противоречий между блоками?
12. Литература вставлена полным утверждённым списком?

# 14. Важное уточнение по вашим правилам

Вы сказали:

> Если ребёнка видел один раз — то он может написать стабильно, если ребёнок проявляет способности сам без помощи взрослого. Остальное — иногда.

Это рабочее правило, но я бы добавил к нему одну служебную метку, чтобы потом не было проблем:

> **S3*** — стабильно по однократному яркому самостоятельному наблюдению.

То есть специалист может написать «стабильно», но в рабочей таблице помечает, что это одно занятие.

Пример:

> По результатам наблюдения ребёнок демонстрирует самостоятельный интерес к сенсорной игре с песком. Проявление зафиксировано однократно, но без поддержки взрослого.

Это позволит вам потом, когда база накопится, разделить:

- S3 — стабильно подтверждено несколькими наблюдениями;
- S3* — стабильно по одному яркому самостоятельному наблюдению.

Но для текущего шаблона можно оставить просто S3, как вы и решили.

# 15. Socratic-проверка перед внедрением

Чтобы шаблон действительно заработал, ответьте себе на три вопроса:

1. Готовы ли вы, что в блоке «Результаты» больше не будет фраз вроде «иногда предлагает новые идеи», если это не стало стабильным?
2. Считаем ли мы созданием условия показ знакомой игрушки, даже если ребёнок потом долго играет сам? По вашему примеру — да, это S1.
3. Оставляем ли мы литературу неизменным блоком для всех, или делаем адаптивный список? Если все блоки из реальных заключений обязательны, то литература тоже обязательна и не сокращается.

Если эти три пункта зафиксировать, шаблон можно отдавать специалистам уже сейчас.
