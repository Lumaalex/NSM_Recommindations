Страница открыта без выполнения JavaScript — конструктор не запустится.

На iPhone и iPad предпросмотр файла из мессенджера или из приложения «Файлы» (Quick Look) показывает только текст и кнопки и не выполняет скрипты. Это ограничение iOS, сам файл исправен: на компьютере он работает двойным кликом, а на телефоне — через Safari по адресу локального сервера.

Как открыть на телефоне (3 шага):
1. На компьютере, лежащем в той же Wi‑Fi сети, запустите: python tools/serve.py
2. На телефоне откройте в Safari напечатанный адрес вида http://192.168.0.10:8000/Конструктор_рекомендаций.html
3. В Safari: «Поделиться» → «На экран «Домой»» — конструктор откроется как приложение и запомнит черновики.

Альтернатива без компьютера: загрузите файл на любой статический хостинг (Netlify Drop, GitHub Pages, ваш сайт) и откройте ссылку в Safari. Черновики и настройки хранятся внутри браузера, интернет не нужен.
