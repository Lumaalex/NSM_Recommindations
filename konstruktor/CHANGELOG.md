# Журнал изменений и переноса (CHANGELOG)

Формат: дата · компонент · что изменено → **где реализовано** (файл, функция/атрибут) →
**что повторить** в Google-версии и других клиентах. Файл ведётся, чтобы итерации переносились
за минуты, а не переисследовались заново.

Легенда компонентов: `V1` = Конструктор_рекомендаций.html · `V2` = Конструктор_ИВ_версия2.html ·
`MAIN` = основная версия 3.2.0 (`main/Конструктор_ИВ_основная_3.2.0.html`, мейн с 2026-10-20) ·
`G` = google/ (Code.gs + Index.html) · `DATA` = source_data.py / Банк_фраз.xlsx / phrases.json ·
`INFRA` = сборка, папка раздачи, тесты, документация.
