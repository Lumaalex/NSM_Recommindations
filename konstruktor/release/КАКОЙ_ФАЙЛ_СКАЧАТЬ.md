# Какой файл скачать

Это папка **раздачи**: здесь лежат точные копии готовых конструкторов с понятными
именами (в имени — форк и версия). Канонические файлы собираются скриптами:
`python tools/build_main.py` -> `main/` (основная версия, мейн) и
`python tools/build.py` -> `fork_v2/` (старый форк V2).

| Файл в этой папке | Что это | Версия | Откуда скопирован |
|---|---|---|---|
| `Конструктор_ИВ_основной_3.2.0.html` | ОСНОВНАЯ версия (мейн, последняя рабочая): оценки сфер по шкале 0…6, шаг «Наблюдения с занятий», банк фраз внутри последнего шага; собирается tools/build_main.py из app/template_main.html + data/phrases_main.json | 3.2.0 | `main/Конструктор_ИВ_основная_3.2.0.html` |
| `Конструктор_ИВ_V2_от_общего_к_частному_2.6.0.html` | V2 «от общего к частному» (старый форк, шкала сфер 5…1 и S0): актуальное состояние -> фразы -> цели -> приёмы -> результаты -> цели на след. период -> рекомендации -> документ; шаг 9 — банк фраз с правками. Проекты (.json) с основной версией НЕ совместимы | 2.6.0 | `fork_v2/Конструктор_ИВ_версия2.html` |

## Как не перепутать

1. В просмотрщике/браузере скачивается **тот файл, который сейчас открыт**.
   Сначала откройте нужный, потом нажимайте «Скачать».
2. Открыли файл — посмотрите на шапку: там написаны форк и версия
   («основная версия · версия 3.2.0» либо «V2 «от общего к частному» · версия 2.6.0»),
   а также в заголовок вкладки браузера.
3. Файлы проектов (.json) между разными версиями конструктора не переносятся.

Папка перезаписывается скриптом `python tools/make_release.py` (он же вызывается
в конце `python tools/build.py`). Копии проверяются по md5 — содержимое совпадает с исходниками.
