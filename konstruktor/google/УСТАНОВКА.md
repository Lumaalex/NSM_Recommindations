# Установка Google-версии конструктора (мобильный доступ по ссылке)

Зачем: файл‑HTML на телефоне открывается через предпросмотр iOS без JavaScript, а локальный сервер
неудобен для рассылки. Веб‑приложение Google Apps Script даёт **постоянную ссылку**: специалист
открывает её в Safari/Chrome на телефоне, работает, а заключения и черновики складываются
на ваш Диск. Мастер‑база фраз — Google Таблица, правится прямо с телефона или компьютера.

Время установки: ~10 минут, один раз.

---

## Шаг 1. Таблица‑мастер-база

1. Откройте вашу папку на Диске → «Новый» → «Загрузить файлы» → выберите `Банк_фраз.xlsx`.
2. Нажмите на загруженный файл правой кнопкой → «Открыть с помощью» → «Google Таблицы».
   Листы (`Фразы`, `Опросник_ключ`, `ИВ2_наблюдения`, `Статусы`, `Поддержка`, `Блоки`,
   `Микроблоки`, `Способности`, `Служебные_фразы`, `Карта_связей`, `Чек-лист`, `Литература`,
   `Направления`) перенесутся как есть.
3. Дальше банк живёт в таблице: добавляете строку на листе `Фразы` — веб‑приложение видит её
   при следующем открытии. Пересборка не нужна.

## Шаг 2. Код приложения

1. В открытой таблице: меню **«Расширения» → «Apps Script»**.
2. Удалите содержимое файла `Code.gs` и вставьте туда всё содержимое файла **`google/Code.gs`**.
3. Слева «+» → **HTML** → назовите файл ровно **`Index`** → вставьте содержимое
   **`google/Index.html`** (расширение добавлять не надо).
4. Сохраните проект (значок диска), назовите его, например, «Конструктор ИВ».

## Шаг 3. Первичная настройка

1. В редакторе Apps Script сверху выберите функцию **`setup`** → «Выполнить».
2. Разрешите доступ (аккаунт → Дополнительно → Перейти на страницу проекта).
3. `setup()` создаст: лист **«Черновики»**, лист **«Предложения фраз»** и папку на Диске
   **«Заключения ИВ»** (туда падают Google Docs и .docx).

## Шаг 4. Публикация ссылки

1. «Развернуть» → «Новое развертывание» → тип **«Веб‑приложение»**.
2. «Выполнять как»: **я**; «Доступ»: **«Все»** (или «Все, у кого есть ссылка»).
3. «Развернуть» → скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
4. Этот URL и рассылайте специалистам и открывайте на телефоне.
   На iPhone: Safari → «Поделиться» → «На экран „Домой“» — получится ярлык‑«приложение».

## Шаг 5. Как этим пользуются

- **Специалист с телефона:** открывает ссылку → заполняет шапку, опросник, блоки →
  «Создать Google Doc» (документ появляется в папке «Заключения ИВ», ссылку можно переслать семье)
  или «Скачать .docx» (файл также сохраняется в ту же папку). Черновик можно сохранить в таблицу
  («Сохранить проект» → лист «Черновики») и дописать позже с любого устройства.
- **Методист:** правит банк на листах таблицы; предложения специалистов падают на лист
  «Предложения фраз» со статусом «на модерации» — после проверки копируете строку на лист `Фразы`.
- **Обновление интерфейса:** если я прислал новую версию — пересоберите `google/Index.html`
  (`python tools/build_google.py`) и замените содержимое HTML‑файла `Index`, затем
  «Развернуть» → «Управлять развертываниями» → «Изменить» → новая версия.

## Чего Google-версия не делает и почему

- **Google Forms вместо веб‑приложения.** Форма умеет только собирать ответы в таблицу:
  без скриптов она не покажет специалисту банк фраз, статусы и ключ «наблюдение → цель → приём →
  рекомендация», не соберёт документ. Форму имеет смысл добавлять поверх, если понадобится
  массовый анонимный сбор наблюдений (например, родителями) — скажите, соберу отдельную.
- **Работа без интернета.** Веб‑приложению нужна сеть. Полностью офлайн работает обычный
  `Конструктор_рекомендаций.html` на компьютере.
- **Печать с телефона.** Safari печатает ограниченно; надёжнее «Создать Google Doc» →
  далее печать/PDF из приложения Google Docs или с компьютера.

## Безопасность и доступы

- Веб‑приложение выполняется от вашего аккаунта: создаваемые документы лежат в вашем Диске.
  Права на папку «Заключения ИВ» задаёте вы (по умолчанию — только владелец).
- Ссылка веб‑приложения — это доступ к интерфейсу, но не к вашему Диску напрямую.
- Черновики хранятся на листе «Черновики» этой же таблицы (доступ виден владельцам таблицы).
