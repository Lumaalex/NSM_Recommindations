# Конструктор рекомендаций — направление «Игровое взаимодействие»

Рабочая версия системы, описанной в чате проекта: специалист наблюдает → кодирует статус
способности → получает готовое заключение по стандарту центра. Формулировки берутся из банка фраз,
их можно перефразировать и дополнять своими.

**Основная (мейн) версия конструктора — 3.3.0.**
Версия видна в шапке и в заголовке вкладки браузера. Всё работает офлайн, без интернета
и без установки программ: файл `main/Конструктор_ИВ_основная_3.3.0.html` открывается двойным
кликом в любом браузере. Отличия от V2: зелёная палитра «ИВ»; шкала сфер 0…6; обязательное
текстовое пояснение при оценке «не проявляется»; шаг 8 «Наблюдения с занятий»; банк фраз —
отдельный режим «Редактор банка» (кнопка «Банк фраз» в шапке, доступна с любого шага).

Резервная линия — форк **V2 «от общего к частному» 2.6.0** (`fork_v2/Конструктор_ИВ_версия2.html`):
содержится для сравнения и на случай отката, обновляется только по отдельной команде.
Старые клиенты (V1 «большая версия» 1.3.0 и Google-версия 1.3.0) из репозитория удалены:
осталось только то, что нужно для работы и пересборки актуальных версий. Их история —
в `CHANGELOG.md`; при необходимости старые файлы можно вернуть из истории git.

### Какой файл скачать (чтобы не перепутать)

1. Браузер и просмотрщик скачивают **тот файл, который сейчас открыт**. Сначала откройте нужный
   файл, только потом нажимайте «Скачать» — папка назначения на содержимое не влияет.
2. Для рассылки берите копию из `release/` — в её имени уже есть форк и версия. Основная версия:
   `Конструктор_ИВ_основной_<версия>.html` (сейчас — 3.3.0); резервная:
   `Конструктор_ИВ_V2_от_общего_к_частному_<версия>.html` (2.6.0).
3. Открыли файл — форк и версия видны сразу: в шапке («Основная версия · версия 3.3.0»)
   и в заголовке вкладки браузера («… · v3.3.0»). На телефоне подстрочник шапки скрыт штатно —
   там версия различается по заголовку и вкладке.
4. Файлы проектов (.json) между разными версиями конструктора **не переносятся**; текущий формат
   основной версии — `project: iv-constructor-main-3_2` (V2: `iv-constructor-v2`). Чужие файлы
   отвергаются при загрузке; черновики и правки банка каждой версии лежат в отдельных ключах
   браузера и не мешают друг другу.

## Как работать специалисту (девять шагов + банк фраз)

В шапке приложения всегда видны **ФИО ребёнка**, **дата заполнения** и **специалист с количеством
занятий** — по ФИО и дате строятся имена файлов проекта (`проект_ФИО_дд-мм-гггг.json`), снимка
оценки и `.docx`, чтобы специалист находил нужного ребёнка: заполнил в начале курса → сохранил →
взял следующего → в конце курса загрузил и дополнил.

1. **Актуальное состояние** (оценка семи сфер). Семь сфер: 1 сенсорная переработка информации ·
   2 эмоциональный фон, саморегуляция, реакция на фрустрацию · 3 интерес к миру, игрушкам, людям,
   играм · 4 контакт, совместное внимание, инициатива, цепочки общения · 5 коммуникация, речь,
   понимание, невербальные средства · 6 игра: уровень, предпочтения, сюжет, правила ·
   7 двигательное планирование, праксис, зрительно-пространственная обработка. Шкала —
   **0…6 по стадиям развития DIR**: 0 — способность не проявляется; далее — высший достигнутый
   уровень. **Плюс сигнальные отметки**: «стресс / перегрузка» и «недостаточно информации» —
   они не считаются отсутствием способности. При оценке 0 обязательно текстовое пояснение —
   оно попадает в документ вместо шаблонной фразы.
2. **Сенсорный опросник (FEDL2i).** Полная таблица индивидуальных особенностей: блоки
   **A** реактивность сенсорных систем, **B** двигательное планирование, **C** реакция на
   звуки/жесты/вербальную коммуникацию, **D** вокализации/жесты/слова/речь, **E** зрительно-
   пространственная обработка, **F** праксис и исполнительные функции — 46 пунктов.
   Каждый блок привязан к своей сфере и дополняет её: A → сфера 1, C+D → сфера 5, B+F → сфера 7,
   E → сфера 7. Мини-таблица своих блоков видна прямо в карточке сферы на шаге 1; по кнопке
   «Собрать текст в документ» блок превращается в готовую формулировку актуального состояния.
3. **Фразы.** После оценки выпадают шаблонные формулировки актуального состояния под этот балл —
   специалист добавляет подходящие кнопкой «+ добавить» (повторное нажатие убирает). Выпадают все
   фразы банка своей сферы и кода оценки; кнопка «+ из банка фраз» открывает модальный просмотр
   с фильтром и поиском.
4. **Цели** предлагаются из поставленных оценок и выбранных фраз; **приёмы** — из выбранных целей
   (к каждому нужен пример с занятия).
5. **Результаты** собираются сравнением с **архивным снимком**: снимок сохраняется в проект или
   в отдельный файл (`снимок_оценки_…json`) и загружается из файла; далее таблица динамики
   «было / стало / ▲+N» и кнопка «в текст результатов».
6. **Цели на следующий период** — отдельный шаг: генерация из текущих целей и сфер с низким
   уровнем, отмена генерации, ручной ввод.
7. **Рекомендации родителям** предлагаются по оценкам и выбранным фразам, с метками сфер;
   **литература**: полный утверждённый список прикладывается всегда, плюс автоматическая
   приоритетная подборка по профилю сфер.
8. **Наблюдения с занятий** — новый шаг основной версии: свободное описание ключевых эпизодов
   (что происходило, что сделал специалист, что ответил ребёнок); используется как доказательная
   база для предыдущих шагов и самопроверки.
9. **Документ** — те же 7 обязательных блоков, самопроверка, кнопки «Скачать .docx»,
   «Копировать текст», «Печать / PDF» (в шапке документа строка «Дата заполнения»).

**Банк фраз — отдельный режим (v3.3.0).** Кнопка **«Банк фраз»** в шапке интерфейса доступна
с любого шага и открывает «Редактор банка» (скрытый шаг 10) — работу с банком не плоской
таблицей, а по логике документа, тремя секциями:
- **Актуальное состояние:** выбираете сферу и оценку (0…6) → видите все фразы этой ячейки →
  добавляете свои; ID (`AS2emo-S2-04`), микроблок и привязка к сфере проставляются автоматически;
- **Конструктор целей:** показывает фразы целей, уже выбранные в документе, и весь банк целей;
  новая цель получает авто-ID `GL-NN`;
- **Приёмы:** для выбранной цели — её связанные приёмы и банк приёмов; новый приём получает
  авто-ID `MT-NN` и сразу связывается с целью.

В редакторе есть кнопка «Табличный вид (правка)» (скрытый шаг 11) — полная таблица банка:
фильтры, правка формулировок прямо в строке, «+ Новая фраза», колонка «В документ»,
экспорт/импорт JSON и CSV, «Вернуть встроенный банк». Возврат из банка — на тот шаг,
с которого открыли. Правки живут в браузере (`localStorage['iv_constructor_bank_main_3_2']`),
переживают перезагрузку и сразу видны в подборе фраз на всех шагах. Готовый банк выгружается
кнопкой «Экспорт JSON» для переноса в мастер-файл.

Черновик автосохраняется в браузере (ключ `iv_constructor_main_3_2_doc`). Кнопки в шапке:
«Сохранить» / «Загрузить» — перенос недописанного заключения между компьютерами одним файлом.

### Оформление и устройства
- **Тёмная / светлая тема** — кнопка в шапке. Выбор запоминается и применяется ещё до отрисовки
  страницы (без мигания).
- **Размер шрифта** — кнопки «A−» / «A+» (85% … 150%, шаг 15%). Настройки темы и кегля хранятся
  в браузере.
- **Печать и PDF не зависят от оформления:** документ всегда печатается чёрным по белому
  в исходном кегле.
- **Телефон и планшет:** вкладки листаются свайпом, широкие таблицы прокручиваются внутри своих
  рамок, кнопки увеличены под палец, горизонтальной прокрутки страницы нет.

## Как открыть на телефоне (если на iPhone видны только кнопки шапки)

Это не баг файла: предпросмотр HTML на iPhone/iPad — из мессенджера или из приложения «Файлы» —
делает **Quick Look**, а он показывает страницу как статику и **не выполняет JavaScript**.
Конструктор в этом режиме показывает красную инструкцию-заглушку вместо пустого экрана.

Рабочий способ на телефоне — открыть конструктор в **Safari** по адресу локального сервера:

1. На компьютере в той же Wi‑Fi сети запустите:
   ```
   python tools/serve.py
   ```
   Скрипт напечатает адрес вида `http://192.168.0.10:8000/main/Конструктор_ИВ_основная_3.3.0.html`.
2. На телефоне откройте этот адрес в Safari (не во встроенном просмотрщике мессенджера).
3. В Safari: «Поделиться» → «На экран «Домой»» — появится ярлык, конструктор открывается как
   приложение. Черновики, тема и кегль хранятся в браузере телефона; интернет не нужен, нужна
   только общая Wi‑Fi сеть с компьютером, пока работает сервер.

Альтернативы: разместить файл на любом статическом хостинге (Netlify Drop, GitHub Pages, ваш сайт)
и открывать ссылку в Safari; или работать с компьютера. На телефоне надёжнее всего кнопка
«Скачать .docx»: файл уходит в «Файлы»/Word.

## Стандарт, зашитый в конструктор

- **Верхнеуровневые блоки не пропускаются никогда.** Пропускать можно только формулировки внутри
  блока — вместо них ставится служебная отметка.
- Обязательные блоки: Актуальное состояние · Цели на период · Приёмы работы · Результаты ·
  Цели на следующий период · Рекомендации · Рекомендуемая литература.
- **Шкала и статусы.** Оценка сфер 0…6 по стадиям DIR + сигнальные отметки (см. шаг 1); в блоках
  документа формулировки несут статус S3/S2/S1/S0/SN. S3 — сам, без подсказки; S2 — сам, но
  нестабильно; S1 — только после слова / действия / аффекта / условия взрослого; S0 — не проявляется
  при достаточных возможностях (требуется текстовое пояснение); SN — не проверялось из-за стресса:
  это не отсутствие способности, приоритет — регуляция и стадия 1.
- **Куда что идёт.** Стабильное → ресурс и «Результаты». Иногда и с поддержкой → «Цели». Нет базы →
  цель на более базовой стадии. «Иногда» и «с поддержкой» в результаты не переносятся.
- **Нет оценки без примера с занятия.** Минимальный формат: «На занятии №__ в ситуации __ ребёнок __.
  Специалист __. Ребёнок __».
- **Три правила против копипаста:** нет цели без наблюдения; нет приёма без цели; нет рекомендации
  без домашнего переноса (родителю — без терминов).

Самопроверка на шаге «Документ» проверяет это автоматически; два пункта остаются ручными
(нет ли слова «стабильно» там, где была поддержка; нет ли противоречий между блоками).

## Как дополнять банк фраз и рекомендаций

### Вариант А — прямо в конструкторе (кнопка «Банк фраз» в шапке)
Открывает «Редактор банка» — добавление фраз по логике документа (сферы+оценки → цели → приёмы)
с автоматическими ID; табличный вид доступен кнопкой внутри редактора. Правки формулировок
сразу доступны в подборе; кнопки «Экспорт JSON» / «Экспорт CSV (для Excel)»
выгружают банк, «Импорт JSON / CSV» загружают его на другом компьютере. Чтобы правка стала общей
для всех специалистов — выгрузите банк («Экспорт JSON»), положите файл поверх
`data/phrases_main.json` и пересоберите: `python tools/build_main.py`.

### Вариант Б — в мастер-файле данных
Мастер-копия данных основной версии — `data/phrases_main.json` (структура соответствует прежней
мастер-базе `Банк_фраз.xlsx`, которая больше не хранится в репозитории):
`ID` (уникальный, например `AS5play-S2-07` = блок AS, микроблок AS5play «Игра», статус S2, № 07),
`Блок` (`AS` / `GOAL` / `METH` / `RES` / `NEXT` / `REC` / `LIT`), `Микроблок`
(`AS1sens` · `AS2emo` · `AS3soc` · `AS4ini` · `AS5play` · `AS6com` · `AS7prax` · `AS8vis`;
рекомендации: `RC1home` · `RC2int` · `RC3sens` · `RC4play` · `RC5frustr` · `RC6peers`),
`Статус` (`S3/S2/S1/S0/SN`), `Текст формулировки`, связи `Цели(ID)`, `Приёмы(ID)`,
`Рекомендации(ID)`, флаг `active` (деактивированные фразы остаются в файле, но не предлагаются).
Старые цифровые коды при сборке переводятся в новые автоматически.
После правки выполните `python tools/build_main.py`.

### Правила пополнения
- Одна фраза = одна мысль; формулировка наблюдаема («поддерживает цепочки контакта в несколько шагов»,
  а не «развивается»).
- Для блока «Рекомендации» — язык родителя, без терминов (со-регуляция, коммуникативные циклы, праксис).
- Связи (`Цели(ID)`, `Приёмы(ID)`, `Рекомендации(ID)`) нужны, чтобы ключ подсказывал
  всю цепочку «наблюдение → цель → приём → рекомендация» одной кнопкой.

## Данные основной версии

Ключ каждой сферы (`sphere_keys`, набор `fedl` из семи сфер): какие формулировки, цели, приёмы,
рекомендации, результаты и цели следующего периода предложить при каждом уровне 0…6 и сигнальных
отметках. Сенсорный опросник: пункты блоков A–F и их шкалы (`sens_fedl`, `sens_scales`), привязка
блоков к сферам. Опросник ИВ2 (55 наблюдательных вопросов, шаг 8). Литература: список + правила
приоритетной подборки. Всё это хранится в `data/phrases_main.json` (версия данных банка 1.3.0),
который вшивается в готовый HTML. Резервная линия V2 использует свои данные
(`tools/source_data.py` → `data/phrases.json`).

## Технические детали (для пересборки)

```
python tools/build_main.py        # собрать основную версию: data/phrases_main.json → main/...html
node   tools/test_main.js         # тесты логики основной версии вне браузера (данные, каскад, .docx, рендер 9 шагов, банк, изоляция хранилищ)
python tools/make_release.py      # обновить release/ — копии обеих версий с версиями в именах файлов
```

Резервная линия V2 (правится только по отдельной команде):

```
python tools/build.py             # собрать V2: data/phrases.json + fork_v2/...html
node   tools/test_v2.js           # тесты логики V2 вне браузера
python tools/test_v2_browser.py   # V2 в headless-браузере: десктоп + iPhone (нужен Playwright)
python tools/serve.py [порт]      # локальный сервер, чтобы открыть конструктор с телефона в Safari
```

- `.docx` собирается прямо в браузере (собственный упаковщик ZIP + WordprocessingML), без внешних
  библиотек; оформление как в заключениях центра: Times New Roman 12 pt, поля 3/1,5/2/2 см,
  нумерованный список литературы.
